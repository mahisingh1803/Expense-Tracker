# Expense Tracker

A clean, beginner-friendly web application built using HTML, CSS, and JavaScript.

## About the Project

Expense Tracker is my first beginner-level web development project, created to practise and strengthen my understanding of frontend development. It is designed to help users record, view, and manage their day-to-day expenses through a simple and user-friendly interface.

## Features

- Clean and beginner-friendly user interface
- Add, view, and manage expense entries
- Dynamic interactivity using vanilla JavaScript
- Styled layout using CSS
- Responsive design for a better user experience

## Technologies Used

- **HTML5** – Structuring webpage content and layout
- **CSS3** – Styling elements and designing the user interface
- **JavaScript (ES6)** – Application logic, DOM manipulation, and interactivity
- **Git & GitHub** – Version control and project hosting

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index1.html` in your browser, or use the Live Server extension to run the project locally.
